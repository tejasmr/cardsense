Quick 3-Minute Setup:
  1. Create a Google Sheet and click Extensions → Apps Script.
  2. Paste the code from google_sheets_backend/Code.gs.
  3. Run setupSpreadsheet once to create the tabs.
  4. Add your Gmail to the allowed_users tab.
  5. Click Deploy → New Deployment → Web app (Access: Anyone) and paste the URL above.
